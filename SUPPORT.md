# Support

`switchbot-mcp` is maintained on a best-effort basis. The project does not
promise response, resolution, compatibility, or security-service timelines.

## Where to ask

- Reproducible bugs: use the GitHub bug report form.
- Feature proposals: use the GitHub feature request form.
- Setup and usage questions: search existing issues, then open a bug report with
  the closest reproducible description if the documentation is insufficient.
- Vulnerabilities: follow [SECURITY.md](./SECURITY.md). Never place vulnerability
  details, credentials, device identifiers, or private logs in a public issue.

Include the Node.js version, operating system, MCP client, transport, exact
command or configuration shape with secrets redacted, expected behavior, and
observed behavior. Use RFC 6761 reserved domains such as `example.test` in
reproductions.

## Scope

Support covers this repository's code and documented package behavior. SwitchBot
accounts, devices, firmware, cloud availability, and Open API policy are owned by
SwitchBot. MCP clients, npm, Smithery, and the official MCP Registry have their
own support and availability boundaries.
