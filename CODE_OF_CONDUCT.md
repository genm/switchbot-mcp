# Code of Conduct

## Expected behavior

Project participants must communicate respectfully, focus criticism on the work,
respect privacy, accept reasonable maintainer decisions, and avoid harassment,
threats, discrimination, sexualized conduct, doxxing, or deliberate disruption.

These expectations apply in repository issues, pull requests, reviews, and other
spaces where a person represents the project.

## Reporting

For observable public behavior, flag the relevant content to `@genm` without
repeating harmful material. For a confidential concern, open a
[conduct contact request](https://github.com/genm/switchbot-mcp/issues/new?template=conduct_contact.yml)
that contains no incident details or personal information. The maintainer will
establish a private channel before requesting details.

The sole maintainer is currently the accountable moderator. If a report concerns
the maintainer, no independent project moderator is available; use GitHub's abuse
reporting process for conduct on GitHub. This limitation must be revisited before
moderation authority is delegated to additional maintainers.

## Enforcement

The maintainer will gather only the information needed, avoid unnecessary public
disclosure, consider context and impact, and may edit or remove content, issue a
warning, limit participation, or permanently ban a participant. Retaliation
against a reporter or witness is prohibited. Outcomes and appeals are handled by
the maintainer, subject to the single-maintainer limitation above.
